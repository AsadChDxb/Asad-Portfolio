Project 01

Enterprise ERP Intelligence Platform — Multi-Agent RAG, SQL & Role-Aware Analytics

A secure enterprise AI assistant integrated across ERP and CRM systems, enabling users to query live business data, retrieve policy knowledge, generate reports and access module-specific insights through a governed multi-agent architecture.

  • ERP-wide integration: Connected major ERP domains including Sales, Accounting, Accounts Payable, Accounts Receivable, Procurement and other operational modules.
  • CRM integration: Extended the assistant beyond ERP data by integrating CRM information into the same conversational workflow.
  • Hybrid agent architecture: Designed supervisor-based routing between RAG agents, SQL agents and hybrid execution depending on the user's request.
  • Role-based data access: Implemented RBAC-aware retrieval so users can only search and retrieve data they are authorized to access.
  • Guardrails & safe execution: Added validation, permission checks and response controls to prevent unauthorized or unsafe data exposure.
  • Data + report output: Users can receive direct answers from live ERP/CRM data as well as generate structured reports from their queries.
  • Audit logging: Logged user queries, agent execution paths and system responses for traceability, governance and operational review.
  • Continuous improvement loop: Logged unanswered or unsupported user questions and converted them into coverage KPIs, helping identify missing data sources and prioritize future agent integrations.
  • Grounded retrieval: Used OpenAI embeddings, Milvus vector search and Cohere reranking for policy and enterprise knowledge retrieval.
  • Production AI service: Exposed the multi-agent orchestration and enterprise AI capabilities through FastAPI services for integration with ERP and CRM applications.
  • Containerized Azure deployment: Packaged the AI services in Docker containers and deployed them on Azure, providing an isolated and scalable runtime for production inference and agent execution.

Project 02

Construction Claims Intelligence — Multi-Agent Evidence Fusion Platform

An AI-powered claims preparation platform for construction projects that consolidates evidence from Microsoft 365 mailboxes, Excel files, ERP data and project documents into one intelligent pipeline. Multi-agent workflows analyze, correlate and organize the evidence required to prepare construction claims and generate structured claim reports.

  • Microsoft 365 integration: Integrated project mailboxes through Microsoft Graph API to retrieve relevant emails and claim evidence directly from M365.
  • Multi-source data ingestion: Combined email evidence with Excel records, ERP transactions, timesheets, BOQs, inspection reports, PDFs and other project documentation.
  • Document intelligence: Applied OCR and parsing pipelines using TrOCR/docTR for scanned and unstructured documents before downstream AI processing.
  • Unified evidence pipeline: Normalized and linked data from structured and unstructured sources so agents could reason across the complete project evidence set.
  • Multi-agent orchestration: Specialized agents handle evidence retrieval, document analysis, ERP/structured-data lookup, correlation and claim-report preparation.
  • RAG & semantic retrieval: Embedded project evidence into ChromaDB/Milvus to retrieve relevant supporting records with source grounding.
  • Claims report generation: Consolidated findings into structured claim-ready evidence and reports for construction claims management and project-control teams.
  • FastAPI service layer: Exposed ingestion, retrieval and multi-agent claims workflows through FastAPI endpoints for integration with enterprise applications.
  • Azure container deployment: Containerized the claims intelligence services with Docker and deployed them on Azure for production execution of document processing, retrieval and agent workflows.

Project 03

Production ML Predictive Analytics Platform — Azure MLOps + ERP Integration

A production machine learning platform for operational forecasting, risk prediction and financial anomaly detection, deployed as containerized inference services on Azure and integrated directly with ERP workflows.

  • Asset maintenance prediction: XGBoost Classifier predicting equipment failure risk from usage, maintenance history and operational signals.
  • Inventory demand prediction: XGBoost Regressor forecasting future material consumption to reduce shortages and excess stock.
  • Project overrun prediction: XGBoost Classifier identifying projects at risk of cost or schedule overruns.
  • Duplicate payment detection: Hybrid XGBoost + Isolation Forest pipeline to identify suspicious or repeated finance transactions.
  • Repeated expense anomaly detection: Isolation Forest model flagging abnormal recurring-expense patterns.
  • Containerized deployment: Packaged trained models and inference services into Docker containers and hosted them on Azure.
  • FastAPI inference layer: Exposed prediction endpoints through FastAPI, allowing ERP modules to request model inference in real time.
  • ERP integration: Connected prediction APIs with ERP dashboards and operational workflows so model outputs were available where business users already worked.
  • MLOps workflow: Used versioned model deployment, containerized releases and controlled inference services to support maintainable production ML delivery.

Project 04

Agentic ERP Action Layer — MCP-Governed Enterprise Operations

An enterprise agent-execution layer that allows AI assistants to securely interact with ERP business operations through MCP-governed tools and existing ERP APIs, without exposing the underlying database directly to the model.

  • MCP tool layer: Exposed approved ERP functions as business-level tools that AI agents can discover and invoke through MCP.
  • Read + action workflows: Supported both data retrieval and controlled transactional operations instead of limiting the assistant to read-only queries.
  • Business-level abstraction: Agents work with capabilities such as outstanding invoices, stock availability, unverified timesheets and sales-order creation rather than raw tables or SQL structures.
  • Existing ERP API reuse: MCP sits above ERP APIs and business services, keeping existing validation and domain logic as the system of record.
  • RBAC-aware execution: Users can only access the tools and data permitted by their existing ERP roles and permissions.
  • Guardrails & validation: Requests pass through authorization checks, input validation and ERP business rules before actions are executed.
  • Human-controlled high-impact actions: Designed sensitive transactional operations to support confirmation or approval before final execution where required.
  • Auditability: Logged user requests, selected tools, execution results and transactional activity for traceability and governance.
  • Extensible tool architecture: New ERP capabilities can be added as MCP tools without changing the agent's core interaction model.
